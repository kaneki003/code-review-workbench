## Alignment rules

The PRD v0.2 is a draft. Specification decisions do not authorize actions on real repositories. Product behavior is in scope; architecture, frameworks, implementation and scheduling are out of scope.

Use the user's supplied grilling practice where it conflicts with the earlier conversation format. Decisions form a dependency tree. Ask only the current frontier, provide a recommendation, and preserve all qualifications. The opening frontier contains only the user's exact purpose question. Advance through the handoff's ten stages; resolve corrections before dependent questions. At completion, present the whole-product understanding and obtain the user's confirmation before revising the PRD.
