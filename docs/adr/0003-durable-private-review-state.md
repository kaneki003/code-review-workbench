# Keep private review state in a shared local SQLite store

Use SQLite through the desktop extension host's built-in driver in a packaged worker, with one operating-system-user app-data root shared by supported local VS Code copies and an explicit ownership/recovery protocol. Transactions reduce the custom write-ordering and crash-recovery burden of JSON review files; the tradeoffs are SQLite schema/backup/deletion maintenance, cross-window coordination and accepting the selected Node driver's release-candidate status with platform/package validation gates. Private review content stays separate from credentials, repository preservation artifacts and GitHub records; clearing follows all app-managed copies while retaining only disclosed necessary recovery facts, as specified in the [storage contract](../design/private-state-storage.md).
